# Controle de estoque com curva ABC e reposição

Evitar faltas e desperdício, ligando o estoque às compras e ao orçamento.

## O que tem aqui
- **Controle de estoque** (`modelos/controle-estoque.xlsx`): Estoque mínimo, ponto de reposição, alertas de compra e curva ABC automáticos.
- **Relatório de perdas** (`modelos/relatorio-perdas.xlsx`): Registro de perdas por motivo, com resumo e gráfico.

## Como funciona
- **Etapas:** fazer o inventário inicial, classificar os itens pela curva ABC, definir estoque mínimo e ponto de reposição, gerar a lista de compras a partir dos alertas e conferir o estoque todo mês.
- **Indicadores:** perdas por mês, faltas de produto, giro de estoque e custo do estoque parado.
- **Base:** cursos de Almoxarifado e de Administração de Materiais e Estoque (SENAI).

## Como publicar na Vercel (sem programar)
1. No GitHub, crie um repositório novo e envie estes arquivos (botão **Add file → Upload files**).
2. Em [vercel.com](https://vercel.com), clique em **Add New → Project** e escolha este repositório.
3. Deixe tudo como está e clique em **Deploy**. Em alguns segundos o site estará no ar.

Para atualizar, troque os arquivos no GitHub e a Vercel publica de novo sozinha.
